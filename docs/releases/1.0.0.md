# Vuewind 1.0.0

The first installable Vuewind release: 60 documented Vue 3 components, a shared theme system, and a new documentation workspace at https://vuewind-two.vercel.app/.

```sh
npm install @bagombeka/vuewind
```

```vue
<script setup>
import { ref } from "vue";
import { VwButton, VwInput } from "@bagombeka/vuewind";
import "@bagombeka/vuewind/style.css";
const name = ref("");
</script>

<template>
  <VwInput v-model="name" label="Workspace name" />
  <VwButton @click="name = ''">Reset</VwButton>
</template>
```

- Named, tree-shakeable component exports and a `VwIcon` helper.
- ESM and CommonJS builds with corresponding TypeScript declarations.
- Vue 3.5 as a peer dependency; no bundled Vue runtime or documentation dependencies.
- Semantic CSS tokens, dark mode, three accent palettes, and reduced-motion support.
- Live documentation examples with package-ready source, props, events, and keyboard notes.
- Searchable navigation, onboarding guides, composed blocks, and responsive layouts.
- Manual npm publication from GitHub Actions with provenance and a downloadable package artifact.

The original dashboard source remains available for migration but is excluded from the package. Calendar and DropdownMenu use native button/disclosure semantics, and application-level accessibility verification remains necessary. There is no backend or authentication service bundled with the components.
