# Vuewind 1.0.1

A security maintenance release for the development toolchain and supported Vue peer versions.

```sh
npm install vue@^3.5.42 @bagombeka/vuewind@1.0.1
```

- Require Vue 3.5.42 or newer within Vue 3, including the SSR attribute-name injection fix. Vue remains an external peer dependency.
- Upgrade the development build and lint tooling to patched versions and remove unused dependency chains. The complete repository audit reports zero known npm vulnerabilities.
- Keep `@bagombeka/vuewind/style.css` unchanged through the Vite upgrade.
- Update the retained dashboard stylesheet to Tailwind 4 and use the official patched SheetJS 0.20.3 release. Verify spreadsheet round-tripping and formula-like text preservation.
- Remove exported row data from debug logging and stop tracking installed dependency code.
- Add audit gates to CI and manual publication, plus weekly dependency update proposals.
- Preserve all 60 public components, 61 named exports, ESM/CommonJS modules, TypeScript declarations, and the documentation's dark default.

The original nine findings in the reported consumer came from its existing Mocha test tooling; a fresh library-only installation had zero findings. This release does not rewrite the already-published 1.0.0 archive.
